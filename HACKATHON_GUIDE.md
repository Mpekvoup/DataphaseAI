## 🎯 Ответы на вопросы жюри

### "Как обучается модель?"
> "Используем Gemini API - уже обученную модель от Google.
> База знаний хранится в векторной БД ChromaDB.
> Можем дообучать через добавление FAQ."

### "Сколько стоит?"
> "Gemini API - БЕСПЛАТНО до 1500 запросов/день.
> Для малого бизнеса (~300 заявок/день) - полностью бесплатно.
> Для масштабирования - ~$5-10/мес на хостинг."

### "Как быстро внедрить?"
> "Развертывание на сервере - 10 минут.
> Подключение Telegram - 2 минуты.
> Загрузка базы знаний - 5 минут.
> ИТОГО: 15-20 минут до production."

### "Поддержка казахского языка?"
> "Да! Gemini поддерживает 100+ языков.
> В коде уже есть language='kk' параметр.
> База знаний может быть на любом языке."
